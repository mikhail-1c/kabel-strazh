# Кабель-страж

Android-страж USB: чужой компьютер без вашего окна видит заряд, а не фото и переписки.

## Что делает сейчас

- Ловит кабель и смотрит, торчат ли **MTP / PTP / ADB**.
- Пока окна нет, считает съём данных аварией: вибрация, шторка, экран поверх замка.
- По отпечатку или PIN открывает данные на 1 / 2 / 5 / 15 минут, потом окно гаснет само.
- Пишет журнал: кто воткнул кабель, когда открылись файлы.
- В **Настройках** три пресета: Обычный, Жёсткий, Замок. Замок запрещает открывать данные вовсе. Любой тумблер после пресета становится «своим набором».
- По умолчанию **выключен**: нет службы и сирены. Включается кнопкой «сейчас» или плиткой **USB** в шторке.
- Скрытый вид: снаружи «Заряд», в недавних не висит, шторка не пишет «съём». Иконку можно убрать из меню — тогда вход только с плитки.

Без прав **Device Owner** приложение не может само выключить провод — только орёт и пишет. С Device Owner на своём телефоне режет передачу файлов и отладку, пока вы сами не откроете окно.

iPhone этим APK не закрыть. Там USB Restricted Mode в системе. Общий слой на оба телефона — железная вставка в кабель (см. `docs/PRODUCT.md`).

## Сборка

### Онлайн (GitHub Actions)

На этой машине SDK нет — APK собирает GitHub.

1. Запушьте workflow `.github/workflows/android.yml` в репозиторий.
2. Откройте [Actions](https://github.com/mikhail-1c/kabel-strazh/actions).
3. Слева **Android** → **Run workflow** → ветка `cursor/android-usb-cable-guard` → **Run workflow**.
4. Когда зелёное — внизу прогона **Artifacts** → `kabel-strazh-debug` → скачайте zip с `app-debug.apk`.

Тот же job сам стартует на каждый push. Это debug-сборка без вашей подписи: для своего телефона через «установку из неизвестных источников» годится, в Play Store — нет.

### Локально

Откройте папку `android` в Android Studio (SDK 35, JDK 17).

```text
cd android
gradlew.bat assembleDebug
```

Поставьте `app/build/outputs/apk/debug/app-debug.apk` на свой Android 8+.

## Device Owner на своём аппарате

Нужен телефон без рабочих аккаунтов или после сброса. Это ломает часть обычных приложений Google. Делайте только на устройстве, которым владеете.

```text
adb shell dpm set-device-owner ru.kabelstrazh.app/.policy.GuardDeviceAdminReceiver
```

Снять владельца: сброс к заводским или `dpm remove-active-admin` (на новых Android чаще только сброс).

## Чего это не умеет

- Не прячет троян и не мешает судебной экспертизе.
- Не спасает от шпиона, который уже сидит в прошивке.
- Не заменяет пароль экрана и шифрование диска.
