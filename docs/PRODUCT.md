# Кабель-страж: продукт

## Задача

Шпионский или «сервисный» ноут воткнули в телефон. Без вашего жеста он должен получить только ватты, не архив жизни.

## Два слоя

### 1. Софт на Android (этот репозиторий)

Телефон сам видит состояние USB (`connected`, `mtp`, `ptp`, `adb`).

| Режим | Поведение |
|---|---|
| Нет кабеля | Тихий фон |
| Кабель, данных нет | Зелёный: только заряд |
| Кабель, данные, окна нет | Красный экран, журнал, вибрация |
| Вы открыли окно | Синий, таймер, потом снова закрыто |

Жёсткая резка MTP/ADB есть только если приложение — Device Owner. Обычный APK на чужом стоковом ROM этого права не имеет.

На iPhone третье приложение USB не режет. Папка `ios/` — компаньон «Заряд»: выключен по умолчанию, в экстренном режиме показывает системные защиты (USB Restricted Mode, Режим блокировки).

### 2. Железо в кабеле (следующий шаг)

Вставка USB-C / Lightning-адаптер:

- VBUS и GND всегда проходят (заряд).
- D+ / D− (и USB 3 TX/RX) по умолчанию разорваны.
- Кнопка + короткий PIN на вставке смыкает данные на N минут.

Это закрывает iPhone и Android одинаково: вражеский ПК физически не видит шину. Софт на телефоне тогда — журнал и сирена, железо — замок.

Не делать «невидимый» кабель для чужой экспертизы. Замок только у владельца устройства.

## Почему не одно приложение на все ОС

- **iOS** третьему коду не отдаёт USB.
- **Windows-страж на своём ноуте** не помогает, если кабель воткнули в чужой.
- **Обычное Android-приложение** не командует контроллером USB.

Поэтому MVP — страж + журнал на Android, железная вставка как второй контур.

## MVP, который уже в коде

1. Фоновая служба после установки и после перезагрузки.
2. Карточка статуса на весь экран.
3. Биометрия / PIN телефона на открытие окна.
4. Журнал последних 200 событий.
5. Опция Device Owner: `DISALLOW_USB_FILE_TRANSFER`, `DISALLOW_DEBUGGING_FEATURES`, на Android 12+ ещё `setUsbDataSignalingEnabled(false)`.
6. Пользовательские настройки и пресеты ужесточения: запрет окна данных, сирена на любой кабель, USB configured как съём, ADB вне окна даже после «разрешить».
7. По умолчанию выключен. Экстренное включение с экрана или плитки USB. Скрытый вид: «Заряд», без недавних, иконку можно снять.
